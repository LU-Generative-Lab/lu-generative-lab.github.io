Where Things Live is a complete ten-week data structures textbook in C++ for CMSC 270 (in theory, not yet (possibly ever) in practice), written by Claude from a single prompt. It comes in web and print editions, with sixteen interactive figures that run the real algorithms, every code file compiled and tested under sanitizers, and a bibliography checked for invented citations. It's less meant as a direct teaching resource and more as a strange sort of benchmark to say: today, this is what frontier AI can do with one paragraph of steering.
