A Claude skill for noticing when something done by hand (or by asking the model, again) should be done by a tool instead. On the third request for the same thing it says so, suggests where the fix belongs (a hook, a tool, a skill, a preference, or a template), and gets out of the way. The idea is borrowed from an old xkcd chart on whether automation is worth the time, adjusted for the fact that every model call has a small cost of its own, and that building tools always takes longer than one thinks.
